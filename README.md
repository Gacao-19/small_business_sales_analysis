# Small Business Sales Data Cleaning & Performance Analysis

## Overview

A simulated small-business sales project focused on data cleaning, transformation, profitability analysis, and management reporting using Microsoft Excel.

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts

## Objectives

- Clean and standardize inconsistent sales records
- Combine sales transactions with product-cost information
- Calculate revenue, COGS, gross profit, and gross-profit margin
- Analyze product and salesperson performance
- Create a clear management report

## Key Findings

- USB Cables generated the highest sales volume.
- Laptop Bags generated the highest revenue and total gross profit.
- Jane demonstrated the strongest gross-profit margin among the salespeople.
- Peter generated the highest revenue.

## Recommendations

- Increase USB Cable inventory due to strong sales volume and profitability.
- Maintain Laptop Bag inventory because of its strong contribution to revenue and gross profit.
- Recognize strong salesperson performance while considering both revenue and profitability.

## Project Deliverables

- Cleaned Excel dataset
- Power Query transformations
- Product profitability analysis
- Salesperson performance analysis
- Management report

> **Note:** This is a simulated portfolio project created for demonstration purposes. The dataset does not represent a real client.
